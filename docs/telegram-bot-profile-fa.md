## About text

برای `/setabouttext` در BotFather کپی کن:

```text
محصولات دیجیتال با قیمت تومانی؛ انتخاب و پیگیری سفارش در تلگرام.
```

## Description

برای `/setdescription` در BotFather کپی کن:

```text
به همه‌چی مارکت خوش اومدی 👋

محصولات دیجیتال را بر اساس دسته‌بندی پیدا کن، توضیحات و قیمت نهایی را به تومان ببین و سفارشت را در تلگرام ثبت و پیگیری کن.

روش کار:
۱) «🛍️ محصولات» را بزن و دسته‌بندی دلخواهت را انتخاب کن.
۲) توضیحات محصول و قیمت نهایی را بررسی کن.
۳) مراحل سفارش و پرداخت را دنبال کن.
۴) وضعیت سفارش را از «📦 سفارش‌ها» ببین.

پشتیبانی: @EZPY9798
```

## فرمان‌های منو

برای `/setcommands` کپی کن:

```text
start - شروع و منوی اصلی
products - دیدن محصولات
orders - سفارش‌های من
help - راهنمای خرید
cancel - لغو مرحلهٔ خرید
```

## ثبت در BotFather

در `@BotFather` دستور `/mybots` را بزن، `@roboticvn686868` را انتخاب کن و از **Edit Bot** این موارد را ثبت کن:

1. **Edit Name:** نام نمایشی بالا
2. **Edit About:** متن About
3. **Edit Description:** متن Description
4. **Edit Botpic:** تصویر پروفایل را از فایل بالا بارگذاری کن
5. **Edit Description Picture:** تصویر معرفی ۶۴۰×۳۶۰ را بارگذاری کن
6. **Edit Commands:** فرمان‌های منو

About تا ۱۲۰ نویسه و Description تا ۵۱۲ نویسه است؛ متن‌های بالا داخل این محدودیت‌ها هستند. [راهنمای رسمی تلگرام](https://core.telegram.org/bots/features)

> اتصال پرداخت پروژه فعلاً در حالت sandbox است؛ پیش از فعال شدن درگاه واقعی، متن عمومی را طوری تغییر نده که پرداخت زنده را تضمین کند.
